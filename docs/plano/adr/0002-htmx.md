# ADR-0002 — HTMX para interatividade

- Status: proposto · Data: 2026-10-13

## Contexto
Registrar peças precisa ser instantâneo (até 2 toques, sem recarregar). O detalhe do
projeto se atualiza periodicamente. Queremos isso sem SPA (ADR-0001).

## Decisão
HTMX em versão fixa, servido pelo próprio site (`app/static/js/htmx.min.js`). Views
devolvem fragmentos quando `HX-Request` está presente e página inteira caso contrário.
Todo formulário funciona sem JavaScript (fallback POST + redirect).

## Consequências
- (+) Interatividade com HTML do servidor; ~14 KB de JS; compatível com CSP com nonce
  (sem `hx-on`/eval; `htmx.config.allowEval = false`).
- (+) CSRF via header `X-CSRFToken` configurado uma vez no layout.
- (−) Lógica de fragmentos precisa de convenção (`_partials/`) e testes dos dois caminhos.

## Alternativas
Alpine.js/Stimulus (complementam, não substituem); JS manual (mais código). Alpine pode
entrar depois para estados puramente visuais, por ADR.
